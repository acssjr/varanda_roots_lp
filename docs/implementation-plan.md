# Plano de implementação

1. Criar a base Next.js com TypeScript, App Router, GSAP e rotas localizadas.
2. Importar e otimizar toda a família Saans em WOFF2.
3. Construir tokens de cor, tipografia, grids e componentes globais.
4. Implementar cabeçalho responsivo, menu mobile e troca PT/EN.
5. Implementar a home editorial com carrossel visual e capítulos cromáticos.
6. Criar páginas internas funcionais para Aulas, Eventos, Curso, Pía e PC e Contato.
7. Aplicar animações GSAP com fallback de movimento reduzido.
8. Validar lint, build, responsividade e execução local.
